# Build series log

## Readout

Experiment registry and decision-document platform with frozen design snapshots, stable salted assignment, health-before-metrics enforcement, calibrated inference, corrected exploratory results, and a live or committed-bundle web client.

Reusable: independent known-truth calibration that counts conclusions; full-input and design fingerprints binding health to analysis; pre-registration hashes with explicit deviations; one renderer for repository claims and product readouts; independent connection and process persistence checks; canonical reset after browser demonstrations.

Finding: daily naive peeking materially inflated null rejection rates in the measured simulations. The public experiment's warning and blocking SRM verdicts differed. Its missing timestamps, gate-exposure records and pre-period covariates were disclosed instead of filled in. Pricepoint's stored log-scale power arithmetic reproduced exactly.

Scope: simulated validation and a retrospective public-data demonstration. Optional uplift and non-randomized modules were deferred. Public API deployment requires unavailable provider configuration and a verified Fly allowance compatible with the zero-cost constraint. Measured values and current deployment evidence: https://github.com/mekala27-45/readout.
