# Statistical methods

All inference uses one observation per randomized unit. Assignment and exposure health records must exist before metric evaluation. Missing values are excluded separately per metric; the health report records missingness by arm. This complete-case analysis needs ignorable missingness. Exposure-conditioned comparisons also require exposure unaffected by treatment for a causal interpretation; random assignment alone does not justify conditioning on exposure.

For means, the effect is treatment mean minus control mean. The standard error combines separate sample variances and sample sizes. Welch degrees of freedom define the two-sided t interval and p-value. For binary proportions, a pooled two-sample z test supplies the p-value and an unpooled Wald standard error supplies the absolute interval. Small samples and outcomes near the boundaries can make this approximation poor. The implementation does not silently truncate intervals to make them look plausible.

Relative lift is treatment mean divided by control mean minus one. Its variance is obtained by a first-order delta expansion, retaining uncertainty from both arms. A zero control mean makes relative lift undefined; this is returned as null. Relative intervals near a zero denominator are unreliable. These are large-sample intervals, not Fieller intervals.

For a ratio of sums, first compute the arm ratio `r = mean(numerator) / mean(denominator)`. Each unit contributes influence `(numerator - r * denominator) / mean(denominator)`. Its sample variance divided by the unit count estimates the arm ratio variance. Combining arms retains within-unit numerator-denominator covariance. Denominators must be positive. The calibration comparator intentionally uses independent Bernoulli sessions and is labeled naive. The ratio scenario uses a stated fixed sample for coverage validation; ratio-metric power planning is not implemented. [Deng, Knoblich and Lu, delta method for online experiments](https://arxiv.org/abs/1803.06336) explains this construction.

An upper winsorization percentile, when declared, is applied using one pooled threshold across arms and saved with the run. The raw result remains in a labeled secondary row. A pooled estimated threshold adds uncertainty not captured by the closed-form Welch interval; the bootstrap cross check resamples already transformed outcomes and is conditional on that threshold. Pre-specifying a historical threshold would give a cleaner confirmatory estimand. The unit percentile bootstrap supplies a cross check for the primary mean or proportion; it is not the decision method. Ratio inference uses the independently calibrated unit delta interval.

Secondary metrics form one Benjamini-Hochberg family and primary-metric segments form another. Adjusted p-values are monotone rank-adjusted p-values; the raw intervals remain ordinary marginal intervals, not simultaneous confidence bands. Segment results are exploratory, and a difference in significance does not establish an interaction. Standard BH assumptions of independence or suitable positive dependence apply. The original cityflow source was unavailable, so this is a canonical implementation independently cross-checked against statsmodels, not a claim of a byte-for-byte port.

The calibration harness generates its own known truths, calls the production inference kernels, and counts rejections or coverage. It does not treat an engine standard error as evidence that its own error rate is correct. Monte Carlo bands use Wilson intervals. CUPED empirical reduction uses the spread of estimates across independently generated replicates and a paired bootstrap interval. Full measured outputs are stored and rendered in RESULTS.md; this document describes assumptions rather than hard-coding empirical findings.
